## Quick Drop Zone 2.5.0

**Quick Drop Zone now updates itself.** It looks for a new version when it starts and every hour after that. When one is ready, it installs it and reopens by itself, once no file is waiting to be filed. Your rules, folders, learning and history stay as they are.

- **Check for Updates…** is in the menu-bar panel's menu, in the app menu, and in **Settings → Updates**, which also turns automatic checks and installs on or off and shows when Quick Drop Zone last checked.
- When a scheduled check finds an update and automatic installs are off, it shows as a row at the top of the menu-bar panel, not as a window that could open behind other apps.
- Every update is signed, and Quick Drop Zone refuses anything that isn't signed by its own key.
- Quick Drop Zone now goes online to check GitHub for a new version of itself. Files, names and contents are never uploaded, and it still has no analytics.

### Install

Install this version by hand once: download `Quick-Drop-Zone-2.5.0.zip`, unzip it, and drag **Quick Drop Zone** into Applications, replacing the old copy. If macOS blocks it, open **System Settings → Privacy & Security** and choose **Open Anyway**. Allow access to Downloads and Desktop again if macOS asks. After that, new versions arrive on their own.

Requires macOS 26 or later.

### Verify the download

`Quick-Drop-Zone-2.5.0.zip.sha256` holds the checksum. In Terminal: `shasum -a 256 -c Quick-Drop-Zone-2.5.0.zip.sha256`.
