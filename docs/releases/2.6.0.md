## Levant 2.6.0

Quick Drop Zone is now **Levant**. It is the same app with a new name, a new app icon file name and a new home on GitHub; nothing about how it files, renames or finds your files has changed.

- The first time Levant opens it asks Quick Drop Zone to quit, then brings over your favorite folders and their notes, rules, learned patterns, activity and settings. Nothing is removed from Quick Drop Zone, so you can delete it once Levant looks right.
- macOS treats Levant as a new app, so it asks again for access to Downloads and Desktop and for permission to send notifications.
- Levant updates itself from its own address. Copies of Quick Drop Zone don't turn into Levant, so install this one by hand once.
